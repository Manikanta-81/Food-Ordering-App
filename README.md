# TastyBites Food Ordering App

A beautiful React-based food ordering demo application with a clean, modern, and responsive user interface that simulates the experience of a real food ordering platform.

## Features

- **Responsive Design**: Works seamlessly on mobile, tablet, and desktop devices
- **Modern UI**: Clean and modern design with smooth animations and transitions
- **Food Menu**: Browse food items by categories
- **Search Functionality**: Search food items by name, description, or tags
- **Food Details**: View detailed information about each food item
- **Shopping Cart**: Add items to cart, adjust quantities, and view total
- **Checkout Process**: Simulated checkout experience

## Tech Stack

- **React**: Frontend library for building user interfaces
- **TypeScript**: For type-safe code
- **React Router**: For page navigation
- **Tailwind CSS**: For styling
- **Heroicons**: For beautiful icons
- **Vite**: For fast development and optimized builds

## Project Structure

```
src/
├── assets/            # Static assets like images
├── components/        # Reusable UI components
│   ├── layout/        # Layout components (Header, Footer, etc.)
│   └── ui/            # UI components (Cards, Buttons, etc.)
├── context/           # React Context for state management
├── data/              # Mock data for the application
├── hooks/             # Custom React hooks
├── pages/             # Main page components
└── types/             # TypeScript type definitions
```

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/food-ordering-app.git
   cd food-ordering-app
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open your browser and navigate to `http://localhost:5173`

## Building for Production

To create a production build:

```bash
npm run build
# or
yarn build
```
